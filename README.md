# ThoxInux (interim personal stub)

**Canonical repository:** [Thox-ai/thoxinux](https://github.com/Thox-ai/thoxinux)

This personal repository (`ttracx/ThoxInux`) is an interim pointer only. It does **not** contain the ThoxInux source tree. All kernel, userspace, boot, evidence, and docs live under the organization repo.

**Apache-2.0** · Rust-first, Linux-ABI-compatible kernel for local-first AI devices.

Built on [Gregory M. Kurtzer’s Ginux](https://github.com/gmkurtzer/ginux) (pinned at `36503bda2d87465765e1b94e65f9d100f27ed5be`) and the ThoxOS Ginux Edition engineering preview.

**Your AI. Your Data. Your Rules.™**

## Status

Engineering preview. See [Thox-ai/thoxinux](https://github.com/Thox-ai/thoxinux) for releases (`v0.9.0`, `v0.9.1` prereleases), quick start, and evidence. No production claim.

## Open vs proprietary

- **Open (Apache-2.0):** kernel (Ginux + THOX patches), boot, userspace, ThoxBeam interface, SDK docs — in [Thox-ai/thoxinux](https://github.com/Thox-ai/thoxinux). See that repo’s [LICENSE](https://github.com/Thox-ai/thoxinux/blob/main/LICENSE) and [NOTICE.md](https://github.com/Thox-ai/thoxinux/blob/main/NOTICE.md).
- **Proprietary:** MeshStack, ThoxKey firmware and secure-boot keys, non-Apache-clean model weights.
